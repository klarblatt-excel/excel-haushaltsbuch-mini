# Excel Haushaltsbuch mini (kostenlos)

Ein kostenloses, kleines Excel-Haushaltsbuch zum Ausprobieren – ideal für den Einstieg in die eigene Haushaltsplanung.

## Aufbau: flache Tabelle
Alle Buchungen stehen in einer **flachen Tabelle** (eine Zeile pro Buchung: Datum, Kategorie, Betrag, Notiz). Keine verschachtelten Blätter – so bleibt alles auswertbar.

## Auswertung mit SUMMEWENNS und Pivot
- **SUMMEWENNS**: Summen pro Monat und Kategorie, z. B. `=SUMMEWENNS(Betrag; Kategorie; "Miete"; Monat; 1)`
- **Pivot-Tabelle**: Per Drag & Drop Monate gegen Kategorien auswerten.
